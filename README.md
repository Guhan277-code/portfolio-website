# Personal Portfolio Website

A personal portfolio website designed to provide a **centralized and continuously updatable profile** instead of relying on a resume that is shared only once. The website brings together my projects, certificates, current learning progress, and future career goals in one place.

## Technologies Used

* HTML
* CSS
* JavaScript
* Bootstrap
* EmailJS

## Features

* Personal introduction and profile
* Education and current learning status
* Skills and technical interests
* Project showcase
* Certificates and achievements
* Contact form with EmailJS integration
* Responsive design using Bootstrap
* Future goals and career direction

## Project Purpose

The main purpose of this website is to create a **living digital portfolio** that can be continuously updated as I learn new technologies, complete projects, earn certifications, and progress toward my career goals.

Instead of sending the same resume repeatedly, this website provides a single place where visitors can view my **current state, projects, certificates, skills, and future goals**.

## What I Learned

Through this project, I learned how to combine **HTML, CSS, JavaScript, and Bootstrap** to build a responsive and interactive website. I also learned how to use **EmailJS** to connect the website's contact form with an email service.

## Future Improvements
